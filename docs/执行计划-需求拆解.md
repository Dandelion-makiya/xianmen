# 《仙门问道》需求拆解与任务清单

> 本文档把两份策划文档的需求拆成可执行的模块。每个模块标注任务、产出和验收条件。

## A. 项目基础

### A1 Godot 项目初始化

- [ ] 创建 Unity 2022 项目，窗口 1600×900，可缩放。
- [ ] 建立 `Assets/Scripts/`、`Assets/Resources/Data/`、`Assets/Scenes/` 目录。
- [ ] 建立 `GameState`、`DataLoader` 静态数据层。
- [ ] 配置 UGUI Canvas、EventSystem 与中文字体。

验收：项目可直接启动，无脚本报错。

## B. 数据层

### B1 数据结构与 JSON

- [ ] 按玩法文档 §6.1 建立 `Card` 数据结构。
- [ ] 按玩法文档 §7.1 建立 `Enemy` 数据结构。
- [ ] 按玩法文档 §8.1 建立 `Relic` 数据结构。
- [ ] 建立 `Event`、`MapConfig`、`StoryText` 数据结构。
- [ ] 编写数据校验脚本，检查字段缺失、id 重复、效果原语非法。

### B2 数据填充

- [ ] `cards.json`：60 张卡（basic 30 / advanced 20 / rare 10）。
- [ ] `enemies.json`：16 种敌人（normal 12 / elite 3 / boss 1）。
- [ ] `relics.json`：15 个遗物。
- [ ] `events.json`：3 个奇遇事件。
- [ ] `map_config.json`：20 节点生成规则。
- [ ] 剧情字段：`flavor`、`lore`、事件文本、结局文本。

验收：数据量与策划文档一致；每张卡的效果都能被战斗引擎执行。

## C. 战斗系统

### C1 基础流程

- [ ] 牌库、手牌、弃牌库、抽牌。
- [ ] 战斗开始洗牌并抽 5 张。
- [ ] 回合开始：罡气清零 → 灵力回满 → 抽 5 张。
- [ ] 收功：手牌全部进弃牌库，灵力清零。
- [ ] 牌库空时弃牌库洗回牌库。

### C2 卡牌效果

- [ ] 支持全部效果原语：damage / multi_hit / block / draw / energy / heal / discard / apply_buff。
- [ ] 支持条件效果：目标有毒煞、本回合出过攻击卡。
- [ ] 支持祭炼后的效果覆盖。
- [ ] 支持稀有度、费用、目标类型。

### C3 状态效果

- [ ] poison、weak、vulnerable、strength、dexterity、thorns、regen 全部实现。
- [ ] 按策划文档 §5.3 规则结算持续时间。
- [ ] 毒煞结算时机明确并写入文档。

### C4 敌人 AI

- [ ] 敌人意图循环按顺序执行。
- [ ] 支持 attack / block / buff / debuff / multi_attack。
- [ ] 敌人成长倍率按确认后的公式应用。
- [ ] 精英与 Boss 的机制字段生效。

### C5 战斗结算

- [ ] 任一方 HP ≤ 0 结束战斗。
- [ ] 战斗胜利掉落：灵石、药材、卡牌选择、遗物。
- [ ] Boss 战胜利进入通关结算。

验收：一场完整战斗可从开局打到胜利/失败，伤害计算与文档一致。

## D. 宗门 Hub 与经营

- [ ] 资源栏：灵石、药材。
- [ ] 坊市：3 张候选卡，按稀有度价格购买。
- [ ] 祭炼：消耗灵石+药材，升级一张卡。
- [ ] 打坐：免费回复最大 HP 的 30%（灵泉遗物可提升）。
- [ ] 领取遗物：战斗/精英掉落后领取。
- [ ] 牌组查看面板。
- [ ] 继续前进按钮。

验收：Hub 内所有操作都能影响当前局状态并持久化。

## E. 地图系统

- [ ] 按规则生成 20 节点线性链。
- [ ] 第 1 节点普通战斗，第 10 节点打坐，第 20 节点 Boss。
- [ ] 精英落在 [6,8] / [11,13] / [16,18] 各 1 个。
- [ ] 奇遇 3 个随机分布，普通战斗填满剩余。
- [ ] 相邻普通战斗连续不超过 3 个。
- [ ] 地图界面只允许进入当前节点。

## F. 奇遇事件

- [ ] 3 个事件按 Story 文档文案展示。
- [ ] 选项按钮显示选项文本。
- [ ] 选择后立即结算效果并回到 Hub。

## G. 界面

- [ ] 主界面：Logo、开始游戏、继续、设置、退出。
- [ ] 战斗界面：玩家状态、敌人状态、意图、手牌、计数、收功按钮。
- [ ] Hub 界面：资源栏、操作按钮、牌组查看。
- [ ] 地图界面：线性节点链、类型图标、当前节点高亮。
- [ ] 结算界面：胜利/失败文案、统计、重新开始。

## H. 存档

- [ ] 当前局状态可保存：节点进度、资源、牌组、遗物、HP。
- [ ] 主界面“继续”读取存档回到 Hub。
- [ ] 新开一局覆盖旧档或要求确认。

## I. 剧情与文案

- [ ] 卡牌 flavor 显示在卡面底部/悬停提示。
- [ ] 遗物 flavor 显示在遗物面板。
- [ ] 敌人 lore 首次遭遇时在图鉴/结算中显示。
- [ ] 事件文本与选项完整。
- [ ] 通关/失败结算显示对应结局文案。

## J. 美术与音效

- [ ] 前三周使用占位图形保证可玩性。
- [ ] 第四周替换：卡框、稀有度边框、卡面图标、意图图标、怪物立绘、背景、字体、按钮。
- [ ] 音效与音乐（确认范围后）。
- [ ] 所有资源版权可商用。

## K. 测试与发布

- [ ] 每周期结束后完整通关一次。
- [ ] 记录平衡问题并同步修改策划文档。
- [ ] Windows 导出包测试。
- [ ] 商店页素材：主图、截图、描述、定价。
