# 《仙门问道》策划文档建议清单

> 目的：在开始编码前，把会影响实现方式的规则一次定清楚。  
> 标记：P0 = 必须确认后才能开发；P1 = 强烈建议确认；P2 = 可选优化。

## P0：必须趁早确认

### 1. 条件效果的数据结构未定义 ✅ 已完成

玩法文档 §6.1 提到“目标有毒煞则 +2”用 `conditional` 标记，但没有给出具体结构。

建议使用：

```json
{
  "type": "damage",
  "value": 6,
  "conditional": {
    "when": "target_has_poison",
    "value": 8
  }
}
```

`when` 至少需要支持：`target_has_poison`（追魂刺、万毒噬心）、`played_attack_this_turn`（剑心通明）。
同意预定义条件效果的Json类型数据结构，后面开发的时候可以继续迭代数据结构

**确认结果（2026-08-17）**：采用上述 JSON 结构；`when` 支持 `target_has_poison` 与 `played_attack_this_turn`；满足条件时用 `conditional.value` 覆盖 `value`；后续开发可继续迭代该结构。已同步至《Xianmen-Path-of-Ascension-1.0.md》§6.1。

### 2. 毒煞结算时机不明确 ✅ 已完成

玩法文档 §5.3 只写“回合开始扣血”，没有区分玩家和敌人。

建议明确为：

- 敌方毒煞在敌方回合开始前结算。
- 玩家毒煞在玩家回合开始时结算。
- 结算后层数 -1。
同意

**确认结果（2026-08-17）**：敌方毒煞在敌方回合开始前结算；玩家毒煞在玩家回合开始时结算；结算后层数 -1。已同步至《Xianmen-Path-of-Ascension-1.0.md》§5.3。

### 3. 剑意和身法对多段效果的计算规则 ✅ 已完成

需要明确：

- 剑意对 `multi_hit` 是每一段都加，还是只加一次。
- 身法对获得罡气是否全部生效。

建议：剑意按每一段伤害分别加成；身法对所有获得罡气的效果生效。

**确认结果（2026-08-17）**：剑意对多段攻击每段单独加成；身法对每次获得罡气的效果都加成；反噬按每次受击触发。已同步至《Xianmen-Path-of-Ascension-1.0.md》§5.3、§5.4。
同意

### 4. 敌人成长公式必须可执行 ✅ 已完成

玩法文档 §7.3 的公式“1 + 0.08 × (节点序号 - 首次出现序号)”存在歧义，而且如果 Boss 也套用公式，第 20 节点的魔尊会过于夸张。

建议改为：

- 成长倍率只作用于普通怪和精英。
- Boss 使用固定数值。
- 公式使用 `1 + 0.05 × (节点序号 - 1)`，上限 1.8，具体系数允许试玩后微调。

**确认结果（2026-08-17）**：Boss 不成长；倍率 = `1 + 0.05 × (节点序号 - 1)`，上限 1.8；HP 与伤害向下取整；系数后续允许重构。已同步至《Xianmen-Path-of-Ascension-1.0.md》§7.3。

### 5. 灵泉遗物效果缺具体数值 ✅ 已完成

玩法文档只写“打坐回复提升”，没有数值。

建议：`灵泉` 使打坐回复从 30% 提升到 50%。

**确认结果（2026-08-17）**：灵泉使打坐回复提升至最大 HP 的 50%（向上取整）。已同步至《Xianmen-Path-of-Ascension-1.0.md》§8.2。

### 6. 天机盘效果需要精确描述 ✅ 已完成

“每回合第一张攻击卡 +2 伤”需要明确多段攻击规则。

建议：每回合玩家打出的第一张攻击卡，本次伤害总额 +2；多段攻击不重复加成。

**确认结果（2026-08-17）**：每回合第一张 `type=attack` 卡伤害总额 +2，多段只加成一次；时机为剑意加成后、气滞减免前。已同步至《Xianmen-Path-of-Ascension-1.0.md》§8.2。

### 7. 商店和卡牌奖励是否允许放弃 ✅ 已完成

建议：

- 坊市：可以不买。
- 战斗卡牌奖励：允许跳过，避免牌组被强行污染。

**确认结果（2026-08-17）**：坊市可不买；战斗卡牌奖励可跳过。已同步至《Xianmen-Path-of-Ascension-1.0.md》§3.3、§9.3。

### 8. 卡牌稀有度的出现节点 ✅ 已完成

当前文档没有规定什么节点能刷出什么稀有度。

建议：

- 节点 1 – 7：只出基础卡。
- 节点 8 – 14：基础卡 + 进阶卡。
- 节点 15 以后：基础卡 + 进阶卡 + 稀有卡。
~~这个不同意，~~（后续统一改为同意 P0 全部方案）

**确认结果（2026-08-17）**：按“节点 1–7 基础卡 / 8–14 基础+进阶 / 15–20 全稀有度”执行，坊市与战斗掉落一致。已同步至《Xianmen-Path-of-Ascension-1.0.md》§9.3。

## P1：强烈建议确认

### 9. 遗物效果重复

`宗门账册`、`灵石矿脉`、`灵石车`、`宗门金库` 都是“战斗胜利 + 灵石”，效果过于同质。

建议：要么调整成不同效果，要么接受它们作为“经济流派”的叠加件，并在文档里说明。

### 10. 坊市折扣取整规则

`炼器阁` 的 -15% 需要定义取整方式。

建议：向下取整，对玩家有利。

### 11. 事件文案不一致

`古墓残卷` 的选项②，玩法文档写“放弃”，故事文档写“收好带走”。

建议统一为故事文档的“收好带走：药材 +8”。

### 12. 存档时机

建议在每次进入 Hub、以及每次完成经营操作后保存；“继续”从最近一次 Hub 状态开始。

### 13. 音频范围缺失

策划文档没有音效和音乐范围。Steam 版本建议至少包含：基础战斗音效、按钮音效、背景音乐。

## P2：可选优化

### 14. 删卡机制

当前 Hub 没有移除卡牌的操作，20 节点后牌组可能过大。

可选方案：在 Hub 增加“闭关遣散”，消耗灵石移除一张卡。如果 MVP 不加入，至少要允许战斗奖励跳过。

### 15. 意图图标清单 ✅ 已完成

美术清单写了 8~10 个意图图标，但玩法文档只有 5 种 action。

建议：正式美术前把意图图标清单明确为：攻击、重击、防御、强化、削弱、多段攻击。

**确认结果（2026-08-17）**：敌人动作枚举补充 `heavy_attack`（重击）与组合动作；意图图标按攻击、重击、防御、强化、削弱、多段攻击、组合动作 7 类。已同步至《Xianmen-Path-of-Ascension-1.0.md》§7.1。

## 不需要修改的部分

- 单角色、单结局。
- 线性地图，无回头。
- 轻剧情：卡牌 flavor、遗物 flavor、敌人 lore、事件、结局。
- 不做过场动画、对话树、好感系统。
- 不扩展经营玩法以外的系统。
