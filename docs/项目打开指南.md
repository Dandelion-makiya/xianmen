# 项目打开指南（Unity 2022）

> 适用：在本机或其他电脑上打开《仙门问道》Unity 工程。

## 一、本机打开步骤

1. 启动 Unity Hub。
2. Projects 页 → 右上角 `Add`（添加）→ 选择项目文件夹 `E:\xianmen`（要选到含 `Assets/`、`Packages/`、`ProjectSettings/` 的那一层，不要选子文件夹）。
3. 选择 Unity 2022.3 LTS 打开。本项目锁定 **2022.3.20f1**（见 `ProjectSettings/ProjectVersion.txt`）；如果本机版本不一致，Unity Hub 会提示安装对应版本，或直接用匹配版本打开。
4. 首次打开会导入资源并生成 `Library/` 缓存，需要等待几分钟，属于正常现象。
5. 打开后：Project 窗口展开 `Assets/Scenes/`，双击 `Main.unity`，点编辑器上方 Play（▶）即可运行。

## 二、许可证问题

- 如果 Unity 提示没有许可证：Unity Hub → 右上角齿轮 Settings → Licenses → Add License → 登录 Unity 账号激活 **Personal（个人版，免费）**。
- 激活需要联网与 Unity 账号（Unity 官网账号或 Unity 中国版账号均可），激活一次后长期有效。

## 三、meta 文件

仓库已为所有资源预置 `.meta` 文件（GUID 固定），保证换电脑、改引用时不会错乱。Unity 首次导入后如果又生成了新的 `.meta`，记得一并提交。

## 四、换电脑 / 同步上下文

Codex 的对话记录保存在当前电脑，**无法直接在另一台电脑上继续同一段对话**。项目的上下文靠「Git + 文档」交接：

1. 新电脑安装 Git、Unity Hub、Unity 2022 LTS。
2. 克隆仓库：`git clone git@github.com:Dandelion-makiya/xianmen.git`
3. 按本文第一节打开 Unity 工程。
4. 先读这几份文档恢复上下文：
   - `docs/执行计划-总览.md`：项目目标与当前进度
   - `docs/执行计划-需求拆解.md`：功能拆解
   - `docs/执行计划-周期排期.md`：四周排期
   - `docs/策划文档建议清单.md`：已确认的设计决策（P0 规则等）
   - `Xianmen-Path-of-Ascension-1.0.md`：玩法唯一事实来源
5. 在新电脑上让 Codex 继续开发时，把上述文档路径提供给 Codex；任何新决策同步写回 `docs/` 并提交，两端以仓库为准。
